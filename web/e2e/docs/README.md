# 工作区入口文档

这份文档是 e2e 固定目录的根级 README：访问裸根地址 `/` 时，工作区按"README 优先"的默认文档策略自动打开它，地址栏随之规范化为 `/doc/README.md`。正文只需一个段落，供布局与默认文档选择断言确认渲染完成。

根级其余文档不参与默认选择：默认策略只考虑第一个 root 的根级文件，子目录与更深层文档都不会被自动打开。frontmatter 中的 `description` 字段随 `/api/files` 下发，悬停侧栏中的本条目时应显示在文件名与标题下方。
