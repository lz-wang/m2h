# 图片加载失败占位回归文档

这份文档用于真实浏览器环境下的图片加载失败回归测试。正文引用一张不存在的图片：加载失败后原位置应当折叠为应用自带的占位图（`/image-load-failed.svg`），顶部出现含原始路径的告警，占位不提供放大能力，也不再显示名称与尺寸提示。

![缺失的图片](images/does-not-exist.png)

这是图片之后的第 1 段。占位图必须保留原文档的占位空间，页面不因失败而出现布局跳动；顶部的资源告警报告的是原始引用路径 `images/does-not-exist.png`，而不是替换后的占位资源地址。

这是图片之后的第 2 段。放大按钮对失败占位隐藏，悬停占位区域不会浮现图片名称提示：占位不是一张可查看的图，Lightbox 与元数据提示都只属于成功加载的图片。
