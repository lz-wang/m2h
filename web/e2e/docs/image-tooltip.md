# 小图片名称提示回归文档

这份文档用于真实浏览器环境下的小图片名称提示宽度回归测试。正文使用同一张 16×16 像素的小图片，分别放置在文档左侧、正文中间与表格右侧接近右边缘的位置：提示的宽度必须由文字内容决定（不受小图片所在的包含块挤压），同时任何位置都不能把页面撑出横向滚动条。提示分为两行：第一行是图片名称，第二行是原始尺寸与格式（按图片自身像素与来源扩展名推导，与页面渲染尺寸无关）。

![短名称](images/tiny.png)

这是图片之后的第 1 段。图片名称提示悬浮在图片底部，宽度上限为 20rem 或视口宽度减去两侧边距中的较小者；名称过长时以省略号截断。小图片自身只有 16 像素宽，如果提示的 shrink-to-fit 宽度被图片的包含块限制，短名称会被压缩到不可读，本文件的断言会捕获这种回归。

这是图片之后的第 2 段。提示与放大按钮同一时机浮现：鼠标悬停图片区域或键盘聚焦放大按钮时出现，对辅助技术隐藏（图片的 alt 已提供名称），不拦截指针事件。元数据行显示图片的固有尺寸 `16 × 16` 与格式 `PNG`——即使页面把图片缩得更小，提示中的尺寸仍然是原图尺寸。

这是图片之后的第 3 段。下面的图片使用很长的名称，用于验证提示宽度到达上限后正确截断，而不是把图片所在的一行撑宽。

![这是一个非常长的图片名称用于验证小图 Tooltip 宽度上限](images/tiny.png)

这是图片之后的第 4 段。长名称提示的宽度不得超过 320 像素（20rem），超出部分显示省略号；即使名称很长，提示也只覆盖图片上方的浮层，不参与正文布局。

这是图片之后的第 5 段。最后一张图片位于表格最右侧列，贴近正文区域右边缘，是横向溢出风险最高的位置：提示居中于图片，若图片贴近视口右缘，提示的右半段可能越出视口，本文件的断言验证页面不因此出现横向滚动条。

这是表格之后的第 1 段。表格默认与正文同宽，右侧列贴近正文区域右缘；全屏宽度模式下正文区域进一步扩展到贴近视口，边缘断言在该模式下同样成立。

这是表格之后的第 2 段。下方的段落只为撑起足够的滚动空间，保证断言运行时页面可以稳定滚动，任何布局异常都会被像素级断言捕获。
