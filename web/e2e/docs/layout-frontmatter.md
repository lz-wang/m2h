# Frontmatter 全屏宽度回归文档

这份文档用于真实浏览器环境下的全屏宽度布局回归测试：正文上方带有 YAML frontmatter 面板，其后是二级标题与若干段落，使文件同时满足“Frontmatter 存在”与“文档目录可以开启”两个条件。

全屏宽度模式下，frontmatter 面板、正文与资源警告共享同一条宽度契约：元素外框宽度等于画布宽度减去两侧 1rem 边距。frontmatter 面板的基础规则声明了 width:100%，box-sizing: border-box 并不把边距计入其中，一旦全屏规则没有把宽度重置为 auto，面板外框就会比画布宽出两侧边距之和。

开启文档目录时，超出的宽度暂时落进目录栏所在的区域，页面还不至于横向滚动；关闭目录后画布右侧失去缓冲，同样的溢出直接变成跨越整个视口的页面级横向滚动条。本文件的断言验证的正是“全屏宽度 + Frontmatter + 目录关闭 + 侧边栏可见”这条完整组合下的横向溢出边界。

## 目标章节

这是目标章节下的第一段。文档目录按标题层级收集条目，这个二级标题保证目录栏非空，从而“隐藏文档目录”的开关在工具栏上可用。

这是目标章节下的第二段。段落高度并不重要，重要的是正文与 frontmatter 面板同时存在于画布中，任何一条宽度规则的回归都会同时影响两者的外框几何。
