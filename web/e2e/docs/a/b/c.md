# 深层文档

这份文档位于 a/b 目录末尾，用于回归目录行置顶吸附与当前文件自动定位的组合行为。正文包含足够多的段落，使窗口可以滚动到非零深度，从而验证侧边栏的吸附与定位不会扰动正文恢复的像素偏移。

这是正文的第 1 段。文件树中的 a 与 b 两级目录在滚动浏览到本文档时会依次吸附在侧边栏顶部，形成两层置顶堆叠。

这是正文的第 2 段。自动定位当前文件时会预留这些吸附目录行的实测高度，保证当前文件行不被吸附堆叠遮挡。

这是正文的第 3 段。吸附行为完全由 CSS sticky 与文件树的嵌套 DOM 结构驱动，不依赖任何滚动监听或祖先状态计算。

这是正文的第 4 段。滚出 a/b 子树后，吸附的目录行会被后续内容自然推走，回到普通文档流。

这是正文的第 5 段。侧边栏的定位与吸附只影响侧栏自身的滚动容器，正文窗口的滚动位置由会话存储中的像素记录负责恢复。

这是正文的第 6 段。段落之间不插入图片、表格或图表，避免异步内容引入与本次回归无关的布局变量。

这是正文的第 7 段。目标滚动深度两百多像素，其后仍有足量段落提供缓冲，避免触底截断影响断言。

这是正文的第 8 段。正文宽度运行在默认的标准模式下，段落换行方式保持稳定，断言使用的像素值可复现。

这是正文的第 9 段。滚动条占据的宽度会影响正文可用宽度，但不影响垂直方向的偏移断言。

这是正文的第 10 段。到这里文档高度已经足够，本用例的断言不再依赖后续内容。
