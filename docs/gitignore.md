# Git Ignore 过滤

m2h 对目录输入默认遵循其中的 `.gitignore` 规则，把"文件发现"与"文件访问"统一到同一个发布范围里：侧边栏、文档路由、静态资源、全文搜索与 `m2h check` 看到的是同一份可见文件集合。本文档记录规则语义、实现边界与有意不支持的能力。

## 功能范围

- **默认开启**。`m2h ./docs` 与 `m2h check ./docs` 都遵循目录内的 `.gitignore`；`--no-gitignore` 关闭（隐藏文件、深度、Glob 与安全限制不受影响，始终生效）。
- **单文件输入不受规则限制**。用户在命令行显式指定一个 Markdown 文件，即是明确的发布动作——即使其所在目录的规则忽略了它，`m2h note.md` 与 `m2h check note.md` 照常工作。
- **多根输入各自独立**。`m2h docs wiki` 中每个目录根应用自己的规则文件，互不影响；同名文件位于不同输入根时分别判定。
- **`.gitignore` 本身永不发布**。Web 发布隐藏点前缀路径（`SkipHidden`），规则文件不会出现在侧边栏；这不影响后端读取其中的规则。

生效的访问入口（拒绝时对访客一律表现为 404）：

| 入口 | 行为 |
| --- | --- |
| `/api/files` | 不返回被忽略文档 |
| `/api/document` | 被忽略文档 404 |
| `/raw/` | 被忽略文档 404 |
| `/assets/` | 被忽略资源 404 |
| `/api/search` | 不索引、不返回被忽略文档 |
| `/doc/` | 被忽略目录无入口文档 |

## 规则语义

匹配语义与 Git 一致，并通过与真实 `git check-ignore` 的对照测试验证（见 `internal/files/gitignore_test.go`）：

- **最后匹配规则生效**；同一文件内后面的行覆盖前面的行。
- **子目录规则覆盖上级**。`notes/.gitignore` 的规则优先于根 `.gitignore`。
- **无前导 `/` 且不含 `/` 的模式匹配任意层级**（`*.log` 匹配 `a.log` 与 `deep/a.log`）；以 `/` 开头或中间含 `/` 的模式相对规则文件所在目录锚定（`/draft.md` 只匹配根级）。
- **目录专用规则**（尾斜杠，如 `build/`）只匹配目录，不匹配同名文件——m2h 在遍历与访问判定时总是知道目标类型。
- **支持否定规则 `!`、递归通配 `**`、字符类与转义**（`\!literal.md`）。
- **被排除的父目录无法从内部恢复**。`private/` 之后的 `!private/public.md` 无效；必须先恢复目录本身（如 `logs/` + `!logs/`）。m2h 按路径组件逐级判定，与 Git 的遍历语义一致。

规则文件缺失按"无规则"处理，正常运行；规则文件不可读（权限）或解析失败时，发现与访问判定显式报错——服务端返回 500（区别于拒绝访问的 404），`m2h check` 中止运行，绝不静默扩大可见范围。

## 实现边界

以下为有意的设计决策，并非完整模拟 `git status`：

- **不读取输入根之外的规则文件**。输入目录可以不是 Git 仓库，m2h 不读取上级目录、`$GIT_DIR/info/exclude` 或用户全局配置，判定结果不依赖执行者的 Git 环境。
- **按请求快照**。匹配器在一次文件发现或一次访问判定时构建，读取路径上的规则文件后即固定；规则文件修改后，下一次请求立即生效，无需重启，也没有文件监视器。正在打开的页面可能需要刷新才能更新侧边栏。
- **规则只过滤，不放宽**。忽略检查叠加在既有的隐藏文件、符号链接、根目录隔离与主动 Web 资源限制之上，任何一层拒绝即拒绝。
- **符号链接双重判定**。先按请求路径（别名）判定，再做文件系统解析后按规范目标判定：可见符号链接指向被忽略文件时拒绝访问；反之被忽略的别名也不能遮蔽可见目标之外的内容。
- **`.gitignore` 不是访问控制机制**。Git 中它控制未跟踪文件的发现；m2h 将其用作发布范围过滤是自身的产品语义，安全边界仍由隐藏文件规则与根隔离保证。

## 解析器

规则解析基于 [denormal/go-gitignore](https://github.com/denormal/go-gitignore)（仅其单文件模式匹配层），层级组合、逐级判定与父目录排除传播由 `internal/files` 实现，并通过 `IgnoreMatcher` 接口对外暴露——规则来源与匹配器解耦，为将来独立的 `.m2hignore` 留出空间。场景表（嵌套、否定、锚定、递归通配、转义、目录规则、同名文件）在单元测试中固化，并在安装了 git 的环境中与 `git check-ignore` 实时对照。
