# 键盘按键（Keys）全览

`++键+键++` 语法渲染为一组键盘按键，多个键用 `+` 连接。按键数据库与 [PyMdown Extensions · Keys](https://facelessuser.github.io/pymdown-extensions/extensions/keys/) 的 English US 键盘一致。本文档穷举全部按键的实时渲染效果，可当作速查表使用。

用法速览：复制 ++ctrl+c++，切窗 ++alt+tab++，任务管理器 ++ctrl+shift+esc++。

## 边界行为

- **大小写不敏感**：`++Ctrl+Shift+Esc++` 与小写写法渲染一致 → ++Ctrl+Shift+Esc++。
- **未知按键保留原文**：`++任意键++` → ++任意键++（无 `key-*` 类、不做翻译），适合展示自定义设备键位。
- **不触发的场景**：普通文本中的加号保持原样——`C++`、`a + b`、跨行内容以及含空格的 `++a b++` 都不会被识别为按键。
- **组合键**：任意多个键用 `+` 连接，例如 ++ctrl+alt+del++、++cmd+shift+period++。
- **与原生 HTML 等价**：`<kbd>Ctrl</kbd>` 手写标签同样有效，但 `++keys++` 语法额外提供标准化的 `key-*` 类名与别名归一。
