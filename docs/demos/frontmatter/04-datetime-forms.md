# 日期时间格式归一

三种合法形态：`T` 分隔的日期时间、空格分隔的日期时间、带引号的纯日期字符串。

预期表现：

- 摘要显示 **created 2026-04-01**：`T` 分隔的时间戳截断为日，且 `create_date` 优先级高于 `create_time`。
- 摘要显示 **updated 2026-04-02**：空格分隔的日期时间同样截断为日。
- 表格中引号被 YAML 解码，`create_time` 显示为 `2026-04-03`。
