# Markdown 表格布局

浏览文档和导出 HTML 时，Markdown 表头保持单行，正文单元格可以换行。
表格超出正文宽度时，在表格内横向滚动。点击表头右侧的排序图标可按该列排序。
也可以按 Tab 移到图标按钮，再按 Enter 或空格排序。

缩窄浏览器窗口，观察「必填」、英文表头和行内代码表头的显示效果。

| 字段 | 必填 | Default configuration value | `options fallback value` | 说明 |
| --- | --- | --- | --- | --- |
| retry | 否 | 3 | 1 | 连接失败时，客户端会在指定的间隔后重试，并在超过重试次数后返回错误。 |
| timeout | 是 | 30 | 10 | 等待服务端响应的最长时间，以秒为单位。 |
